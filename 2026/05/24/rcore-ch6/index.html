easy-fs

封装一个简单的file system（crate的形式），以实现简单的文件系统磁盘布局
easy-fs-use是一个能在开发环境（Ubuntu）中运行的的program，以测试easy-fs

easy-fs use the allocate crate provided by the Rust to separate the os kernel memory manager,and avoid invoking the memory set related functions.At the underlying driver level,a polling method is used to access the virtio_blk virtual disk device,thus avoiding access to kernel functions related to peripheral interrupts.Easy-FS avoids direct access to process-related data and functions in its design, thereby isolating it from the operating system kernel’s process management.

Divide into five level:

  • block device interface: define the trait about the block reading and writing
  • block cache: Cached the data in disk blocks in memory,avoiding reading and writing the disk block frequently.
  • disk data structure: combine all the core data structure mentioned above,define the basic new allocate deallocate functions.
  • inode: manager the inode,and implement the file building/opening/reading/writing… (member functions) to support the os related syscalls

easy-fs disk layout overview

In the easy-fs disk layout, the disk is divided into 5 contiguous regions with different attributes in ascending order of block number:

  • Super block: provide the fs legal inspection,and could locate other contiguous region position
  • inode bitmap: records which inodes in the subsequent inode area have been allocated and used, and which have not yet been allocated.(divide into several blocks)
  • inode area: divide into several blocks which store several inodes
  • data bitmap: record which data blocks in the subsequent data area have been allocated and used, and which have not yet been allocated.
  • data area: save the file or directory specific data content.
