This post aim at recording the reading memory about OSTEP’s Persistent part.

I/O device

standard device

Combine with command register, status register and data register, the standard I/O device have their own interface to communicate with system while this interface have their own protocols.The inner structure has some processor and other firmwares.

use interrupt to decline the cpu expense

When a process send a request to device, this process could sleep until the device finishing the operation.This process would slow a interrupt to call the trap-handle.

use DMA to transfer data highly

DMA is a device that could coordinate the data transfer between memory and device.The os could tell the DMA engine where the data is in memory through programming.

use previliage instructions or memory I/O relocate

hard disk driver

Each disk have several sector which is composed of 512 byte blocks.A single 512-byte write is atomic.And the contiguous sector have faster query speed than non contiguous one.

RAID

RAID is a way to organize multiple disks to improve speed, fault tolerance,ot both.

file and directory

inode

Everything is file.The file is a linear bytes array, which each bytes could read and write.
Each file has their low-level name: inode number.

system calls

open(“foo”, flags) => open a file and return a fd.
read , write(specify_fd, “context”, length) => return read or write length,
both read and write system calls are scan the file sequentially.
off_t lseek(int fd, off_t offset, int whence) could move the file offset.

The write syscall would not write the change into the disk,while store in a buffer for a while.The fsync would flush the data to disk directly.

file rename

rename(old_name, new_name) => atomic

directory

File system could store each file metadata with struct stat.

Use the stat instruction(command line tool) could view the file stat.And the fstat(),stat(),lstat() have the same function to get file status in libc(<sys/stat.h>).

linkage

hard link

Use the ln to build the other name while the two file point to single inode number.

soft link

When use rm demo.txt then would cause the dangling reference.Then use cat demo2.txt would show no such file or directory.
