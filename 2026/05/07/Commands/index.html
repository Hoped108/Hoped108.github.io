Searching

grep search text in a file

grep pattern file => is the usage of this file grep command.The pattern is regex.
grep would exit with the 1 when success.(0 would be return when fail)
Use the - could get from standard output

option meaning example 示例结果
-n 显示匹配行的行号 grep -n "main" main.c 输出包含 main 的行，并在前面显示行号，例如 12:int main()
-i 忽略大小写 grep -i "error" app.log ERROR、Error、error 都会被匹配出来
-r / -R 递归搜索目录 grep -rn "TODO" src/ 在 src/ 下所有文件中搜索 TODO，输出文件名、行号和匹配行
-v 反向匹配，显示不包含该模式的行 grep -v "debug" app.log 输出所有不包含 debug 的日志行
-w 匹配完整单词 grep -w "int" main.c 只匹配单独的 int，不会匹配 print 里的 int
-l 只显示包含匹配内容的文件名 grep -rl "TODO" src/ 只列出含有 TODO 的文件路径，不显示具体行
-c 统计匹配行数 grep -c "error" app.log 输出匹配 error 的行数，例如 5
-A N 显示匹配行之后 N 行 grep -A 3 "panic" app.log 输出 panic 所在行以及后面 3 行
-B N 显示匹配行之前 N 行 grep -B 3 "panic" app.log 输出 panic 所在行以及前面 3 行
-C N 显示匹配行前后 N 行 grep -C 3 "panic" app.log 输出 panic 所在行以及上下各 3 行
-E 使用扩展正则表达式 `grep -E “error fail
-o 只输出匹配到的部分 grep -o "[0-9]\\+" file.txt 只输出文本中的数字部分，而不是整行

rg
ripgrep(rg) is recursively search the current directory for lines matching a pattern.By default,rg will ignore the .gitignore and automatically skip hidden files/directory and binary files.
-e PATTEN --regexp=PATTEN
A pattern search recursively.

-f PATTERFILE --f=PATERFILE

-i => ignore the case(insensitively)
-v => show the inverted matching.(print the not match lines)
-g => control which file paths are included or excluded during search.

This command would search matches without ().Because the rg treats this pattern as regex by default,and ()means a group,not literal parentheses.
Use -F when you want rg to treat your pattern as plain text, not regex.

option meaning example 示例结果
-n 显示匹配行的行号，通常默认开启 rg -n "main" 输出匹配行，并带有文件名和行号
-i 忽略大小写 rg -i "error" ERROR、Error、error 都会被匹配出来
-S 智能大小写 rg -S "Error" 模式里有大写时区分大小写，模式全小写时忽略大小写
-w 匹配完整单词 rg -w "main" 只匹配单独的 main，不会匹配 domain 里的 main
-F 按普通字符串搜索，不把模式当正则 rg -F "data_block()" src/ 精确匹配 data_block()，括号不会被当成正则分组
-e 指定搜索模式，适合多个模式或以 - 开头的模式 rg -e "error" -e "panic" 匹配包含 error 或 panic 的行
-t TYPE 只搜索指定语言或文件类型 rg -t rust "fn main" 只在 Rust 文件中搜索 fn main
-g GLOB 按 glob 包含或排除文件路径 rg "TODO" -g "*.rs" 只在 .rs 文件中搜索 TODO
-l 只显示包含匹配内容的文件名 rg -l "TODO" 只列出含有 TODO 的文件路径
-c 统计每个文件中的匹配行数 rg -c "TODO" 输出每个文件里匹配 TODO 的行数
-o 只输出匹配到的部分 rg -o "[0-9]+" file.txt 只输出文本中的数字部分，而不是整行
-A N 显示匹配行之后 N 行 rg -A 3 "panic" 输出 panic 所在行以及后面 3 行
-B N 显示匹配行之前 N 行 rg -B 3 "panic" 输出 panic 所在行以及前面 3 行
-C N 显示匹配行前后 N 行 rg -C 3 "panic" 输出 panic 所在行以及上下各 3 行
--hidden 搜索隐藏文件和隐藏目录 rg --hidden "token" 会搜索 .env、.config/ 这类隐藏路径
--no-ignore 不遵守 .gitignore 等忽略规则 rg --no-ignore "target" 会搜索本来被忽略的路径，例如 target/
--files 只列出会被 rg 搜索到的文件 rg --files -g "*.rs" 列出当前目录下符合条件的 Rust 文件
