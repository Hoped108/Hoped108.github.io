⚙️ 1. 逻辑推理

1.1 命题逻辑的核心：范式与等值式

命题逻辑研究命题（能判断真假的陈述句）之间的关系。其核心是将复杂的逻辑语句转化为标准形式，以便于推理和判定。

-

主析取范式与主合取范式

- 

**极小项**：一个包含所有命题变元或其否定一次的合取式。每个极小项对应一个且仅有一个成真赋值。例如，对于两个变元P和Q，极小项有四个：`P∧Q`（11为真）、`P∧¬Q`（10为真）、`¬P∧Q`（01为真）、`¬P∧¬Q`（00为真）。

- 

**主析取范式**：一个命题公式的等值式中，由所有使其为真的赋值对应的极小项进行析取所构成的公式。**主析取范式唯一地表征了公式的逻辑功能，其本质是公式的所有成真Scenario的并集**。

- 

**主合取范式**：一个命题公式的等值式中，由所有使其为假的赋值对应的极大项（所有变元或其否定一次的析取式）进行合取所构成的公式。**主合取范式本质是公式的所有成假Scenario的交集**。

- 

**求法**：真值表法（直接）、等值演算法（熟练后更高效）。等值演算需熟练运用以下基本等值式。

-

基本等值式

必须熟练掌握的16组基本等值式是逻辑演算的基石，例如：

- 

**德摩根律**：`¬(P ∨ Q) ⇔ ¬P ∧ ¬Q`；`¬(P ∧ Q) ⇔ ¬P ∨ ¬Q`。这是对“或”的否定变成“且”，以及对“且”的否定变成“或”的量化描述。

- 

**蕴含等值式**：`P → Q ⇔ ¬P ∨ Q`。这是**消去蕴含词最关键的工具**，它将条件关系转化为更基本的“或”和“非”运算。

- 

**假言易位**：`P → Q ⇔ ¬Q → ¬P`。即原命题和逆否命题等价。

- 

**分配律**：`P ∧ (Q ∨ R) ⇔ (P ∧ Q) ∨ (P ∧ R)`；`P ∨ (Q ∧ R) ⇔ (P ∨ Q) ∧ (P ∨ R)`。这与代数中的乘法对加法的分配律类似，但逻辑中的“与”和“或”也满足分配关系。

-

推理理论：证明方法与规则

推理是从前提（已知为真的命题）合乎逻辑地推出结论的过程。

- 

**核心推理规则**（**证明时必须明确写出所用规则名**）：

- 

  **假言推理**：`P → Q, P ⇒ Q`。如果P蕴含Q，并且P为真，那么Q为真。

- 

  **拒取式**：`P → Q, ¬Q ⇒ ¬P`。如果P蕴含Q，但Q为假，那么P为假。

- 

  **假言三段论**：`P → Q, Q → R ⇒ P → R`。传递性。

- 

**主要证明方法**：

- 

  **直接证明法**：从前提出发，一步步应用推理规则，直接得到结论。

- 

  **附加前提证明法**：当结论是蕴含式 `P → Q`时，可以把 `P`作为附加前提，目标变为证明 `Q`。这相当于要证明 `(前提集合) ∧ P → Q`。

- 

  **归谬法（反证法）**：假设结论为假，然后推出矛盾，从而证明结论为真。这是非常强大的证明方法。

🧮 2. 集合代数

2.1 关系：等价与偏序

集合论不仅研究元素归属，更研究元素间的关系，其中等价关系和偏序关系是两大支柱。

-

等价关系与划分

- 

**定义**：设R是集合A上的二元关系，如果R同时满足：

1. 

   **自反性**：∀a∈A, (a, a) ∈ R。

2. 

   **对称性**：若 (a, b) ∈ R，则 (b, a) ∈ R。

3. 

   **传递性**：若 (a, b) ∈ R 且 (b, c) ∈ R，则 (a, c) ∈ R。

   则称R为A上的等价关系。

- 

**等价类**：对于a∈A，集合 `[a]₍ᵣ₎ = {x | x∈A 且 (a, x) ∈ R}`称为a关于R的等价类。等价类中的元素彼此“等价”。

- 

**商集**：A上关于R的所有等价类构成的集合 `A/R = {[a]₍ᵣ₎ | a∈A}`称为A关于R的商集。

- 

**划分**：商集 `A/R`构成了集合A的一个**划分**。即，它将A分割成若干互不相交的非空子集（等价类），这些子集的并集就是A本身。**等价关系与划分是一一对应的**。

-

偏序关系与哈斯图

- 

**定义**：设R是集合A上的二元关系，如果R同时满足：

1. 

   **自反性**。

2. 

   **反对称性**：若 (a, b) ∈ R 且 (b, a) ∈ R，则 a = b。

3. 

   **传递性**。

   则称R为A上的偏序关系，通常用符号`≼`表示。集合A和其上的偏序关系`≼`一起称为偏序集，记作`(A, ≼)`。

- 

**哈斯图**：是表示有限偏序集的直观工具。画法：省略自反环（每个点与自己比）；省略由传递性可推出的边（若a≼b且b≼c，则省略a到c的边）；将元素按偏序关系从低到高排列，所有边的箭头向上，故可省略箭头。哈斯图清晰地显示了集合中的极大/极小元、最大/最小元（如果存在）以及元素间的可比性。

2.2 函数：单射、满射、双射

函数是一种特殊的关系，要求A中每个元素在B中都有唯一像。

-

单射：如果 f(a₁) = f(a₂)必然推出 a₁ = a₂，则称f为单射（一对一）。像相同，原像必相同。

-

满射：如果对任意b∈B，都存在a∈A使得f(a)=b，则称f为满射（映上）。B中每个元素都有原像。

-

双射：既是单射又是满射的函数。双射函数存在反函数，且建立了集合间的一一对应关系。

2.3 闭包与Warshall算法

关系的闭包是指包含原关系R并具有某种性质（自反、对称或传递）的最小关系。

-

传递闭包：R的传递闭包记作R⁺，是包含R的最小的传递关系。(a, b) ∈ R⁺当且仅当存在一条从a到b的长度至少为1的路径。

-

Warshall算法：计算传递闭包R⁺的高效算法，基于邻接矩阵。

算法思想：动态规划。依次考虑每个顶点k作为“中转站”，如果从i可以到k，并且从k可以到j，那么就从i到j建立一条通路。

2.4 容斥原理

用于计算有限集合的并集元素个数，解决重叠计数问题。

对于两个集合：|A ∪ B| = |A| + |B| - |A ∩ B|

对于三个集合：|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|

文氏图是理解和应用容斥原理的绝佳直观工具。

🔗 3. 图论综合（深度解析）

3.1 连通性：深入理解割集与连通度

图的连通性衡量图的“鲁棒性”，即需要破坏多少结构才能使图不连通。

-

点割集与点连通度κ(G)

- 

**点割集**：一个顶点集合S，如果从图G中删除S中的所有顶点（及与之关联的边）后，图的连通分支数增加，且S是极小的（即S的任何一个真子集都不再是点割集），则S称为点割集。

- 

**点连通度**：非平凡连通图G的点连通度κ(G)是G的最小点割集所包含的顶点数。完全图Kₙ的点连通度定义为n-1。κ(G)越大，图越不容易因顶点故障而断开。

-

边割集与边连通度λ(G)

- 

**边割集**：一个边集合T，如果从G中删除T中的所有边后，图的连通分支数增加，且T是极小的，则T称为边割集。

- 

**边连通度**：连通图G的边连通度λ(G)是G的最小边割集所包含的边数。

-

重要不等式：对任意图G，有 κ(G) ≤ λ(G) ≤ δ(G)，其中δ(G)是图的最小度。

3.2 特殊的图：判定定理与应用

-

欧拉图与欧拉回路

- 

**定义**：存在一条回路，经过图中每条边恰好一次，并回到起点。

- 

**核心定理**：一个无向连通图是欧拉图（存在欧拉回路）的**充要条件**是**图中每个顶点的度数都是偶数**。这个条件是简洁而完备的。

- 

**欧拉通路**：存在一条通路，经过图中每条边恰好一次，但无需回到起点。无向连通图存在欧拉通路的充要条件是恰有两个顶点的度数为奇数（作为路径的起点和终点）。

-

哈密顿图与哈密顿回路

- 

**定义**：存在一条回路，经过图中每个顶点恰好一次，并回到起点。判断一个图是否是哈密顿图是图论中著名的难题，**没有像欧拉图那样简单的充要条件**。

- 

**常用判定定理**：

- 

  **充分条件（Dirac定理）**：对于一个顶点数n≥3的简单图，如果每个顶点的度都至少为n/2，则该图是哈密顿图。

- 

  **必要条件**：如果图是哈密顿图，那么对于任意一个非空顶点子集S，从图中删除S后，剩下的连通分支数不会超过|S|。这个条件常用来证明一个图*不是*哈密顿图。

-

平面图与欧拉公式

- 

**定义**：可以画在平面上使得边除顶点外无交叉的图。

- 

**欧拉公式**：对于一个连通的平面图，设v是顶点数，e是边数，r是面数（包括最外部的无限面），则有公式：**`v - e + r = 2`**。这是平面图的一个强大工具。

- 

**库拉托夫斯基定理**：一个图是平面图**当且仅当**它**不包含**与`K₅`（5个顶点的完全图）或`K₃,₃`（完全二分图）**同胚**的子图。这是判定平面图的理论基础。

-

二部图与匹配

- 

**二部图**：顶点集可划分为两个不相交子集X和Y，使得每条边的两个端点分别属于X和Y。

- 

**匹配**：一个边的集合，其中任意两条边没有公共顶点。

- 

**Hall定理**：二部图G=(X∪Y, E)存在一个匹配覆盖X中所有顶点的**充要条件**是：对于X的任意一个子集S，其邻集N(S)（Y中所有与S中顶点相邻的顶点集合）的大小满足 `|N(S)| ≥ |S|`。

- 

  **举例**：X={A, B, C}, Y={1, 2, 3}, 边为A-1, A-2, B-2, C-3。检查所有S：S={C}时，N(S)={3}，满足。S={A,B}时，N(S)={1,2}，满足。所有子集都满足Hall条件，故存在覆盖X的匹配（如A-1, B-2, C-3）。若删除边C-3，则对于S={C}，N(S)=∅，条件不成立，故不存在覆盖X的匹配。

🔢 4. 排列组合、递推与生成函数

4.1 生成函数：计数的强大工具

生成函数（母函数）的核心思想是将一个计数序列 a₀, a₁, a₂, ...编码为一个形式幂级数的系数：G(x) = a₀ + a₁x + a₂x² + ...。通过代数运算求解计数问题。

-

典型应用：不定方程整数解的个数

- 

**问题**：求方程 `x₁ + x₂ + x₃ = 5`的非负整数解的个数。

- 

**生成函数构造**：每个变量xᵢ的取值是0, 1, 2, ...，其生成函数为 `(1 + x + x² + x³ + ...)`，代表取0（x⁰）、1（x¹）、2（x²）等值。整个方程的生成函数是三个变量的生成函数之积：

`G(x) = (1 + x + x² + ...)³`

- 

**函数简化**：`1 + x + x² + ... = 1/(1-x)`。所以 `G(x) = 1/(1-x)³`。

- 

**寻求系数**：我们要求`x⁵`的系数。利用广义二项式定理展开 `1/(1-x)³`：

`1/(1-x)³ = Σ_{k=0}^∞ C(3+k-1, k) * x^k = Σ_{k=0}^∞ C(k+2, k) * x^k`

因此，`x⁵`的系数是 `C(5+2, 5) = C(7,5) = 21`。

- 

**结论**：非负整数解的个数是**21**。这个结果与组合意义“将5个不可区分的球放入3个可区分的盒子中”的方案数一致。

4.2 多重集的r-组合数

从k种元素的多重集中选取r个元素，若每种元素无限供应，则方案数为 C(r + k - 1, r)。这正是上面生成函数方法得到的结果。
