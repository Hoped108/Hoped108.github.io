下面给你一个“前五章（谢希仁第8版）闭卷冲刺”重点复习目录，按你们题型（单选/多选/简答/计算/综合应用/附加）来组织。你复习时就按这个目录逐条打钩。

计算机网络（前五章）重点复习知识点目录

0. 高频“通用基础”（所有题型都可能出现）

  • 网络分层思想：OSI 七层 / TCP/IP 四层（各层功能、典型协议、典型设备）
  • 服务 vs 协议、接口、SAP、PDU（名词解释/选择题常考）
  • 面向连接 vs 无连接、可靠 vs 不可靠
  • 交换方式：电路交换 / 报文交换 / 分组交换（优缺点、对比）
  • 性能指标：时延组成（发送/传播/处理/排队）、RTT、吞吐量、带宽、利用率
  • 时延带宽积、往返时延对协议效率影响（简答/计算）
  • 应用层只作理解（若老师喜欢扩展可能出附加题：DNS/HTTP/SMTP 的基本过程）

第1章 概述（选择题+名词解释“送分区”）

  • 计算机网络定义、组成：资源共享、互连、分布式
  • 网络分类：LAN/MAN/WAN、按拓扑（星/总线/环/网状）
  • 协议三要素：语法/语义/同步
  • 分层的好处与代价（复用/解耦/可扩展 vs 开销/复杂度）
  • 典型封装/分用过程：数据在各层加首部/尾部
  • TCP/IP 体系结构：每层代表协议（IP、TCP、UDP、ARP、ICMP、以太网、PPP 等）

第2章 物理层（计算题高频：香农/奈奎斯特；选择题：编码/复用）

2.1 基本概念

  • 物理层作用：比特流传输、接口特性（机械/电气/功能/规程）
  • 信道、码元、波特率、比特率关系；基带/频带

2.2 编码与调制（选择题常考）

  • 典型编码：NRZ、曼彻斯特、差分曼彻斯特（特点：自同步、带宽占用）
  • 调制基本理解：ASK/FSK/PSK/QAM（知道哪个抗噪强、频谱效率高即可）

2.3 复用（多选常考）

  • FDM/TDM/WDM/CDM（定义、区别、应用场景）
  • 统计时分复用（STDM）基本思想

2.4 传输介质（选择题）

  • 双绞线/同轴/光纤（衰减、抗干扰、带宽、距离）
  • 无线与传播：自由空间损耗、干扰概念（了解）

2.5 计算题核心公式（必会）

  • 奈奎斯特定理：无噪声信道最高码元速率与带宽关系（知道形式与结论）
  • 香农公式：有噪声信道容量与带宽、信噪比关系（会代入算容量/带宽/信噪比）

第3章 数据链路层（选择题+简答+计算题：CRC/滑动窗口/MAC）

3.1 基本功能（名词解释/简答）

  • 成帧、差错检测、可靠传输（ARQ）、流量控制
  • 透明传输：字节填充/比特填充（PPP/HDLC思路）
  • 点对点链路 vs 广播信道

3.2 差错检测与纠正（计算题高频）

  • 奇偶校验（了解局限）
  • CRC 循环冗余校验：生成多项式、校验码计算流程（必会“除法”思路）

3.3 可靠传输机制（简答/计算）

  • 停止-等待 ARQ：效率与 RTT 关系（可能算利用率）
  • 滑动窗口：Go-Back-N / Selective Repeat（窗口大小约束、累计确认/选择确认）
  • 流量控制：窗口/确认机制

3.4 介质访问控制 MAC（综合题常考）

  • ALOHA（纯/时隙）：吞吐量特性（知道谁更好）
  • CSMA：1-坚持/非坚持/p-坚持
  • CSMA/CD（以太网）：碰撞检测、二进制指数退避、最小帧长与冲突域（经常出选择/简答/计算）
  • CSMA/CA（802.11）：为什么不能CD、RTS/CTS、退避（理解对比）
  • 以太网帧结构（目的/源MAC、类型、FCS）、MAC地址特性
  • 交换机 vs 集线器（冲突域/广播域，常考对比）

第4章 网络层（计算题+综合应用题核心：IP编址/子网/CIDR/路由）

4.1 网络层服务与核心概念（简答）

  • 虚电路 vs 数据报（对比、优缺点）
  • 路由器作用、转发与路由选择区别

4.2 IPv4 地址与子网划分（计算题王炸）

  • IPv4 地址结构：网络号/主机号；A/B/C 类与私有地址段（选择题）
  • 子网掩码、子网划分：可用主机数、子网数、网络地址/广播地址（必会）
  • CIDR：斜杠表示、最长前缀匹配（综合题必考点）
  • 地址聚合/路由聚合（会判断是否可聚合、聚合后前缀）

4.3 ARP / ICMP（简答/选择）

  • ARP：IP→MAC 的解析过程、ARP缓存、广播请求单播应答
  • ICMP：差错报告与询问报文；ping/traceroute 基本原理（常被拿来出综合题）

4.4 IP 数据报（简答/选择/计算）

  • IPv4 首部关键字段：TTL、标识/DF/MF、片偏移、首部校验和
  • 分片与重组：给 MTU 会算分片数量/每片数据大小/偏移（计算题常见）

4.5 路由选择算法（综合题常考）

  • 路由选择基本概念：静态/动态、自治系统 AS
  • 距离向量（RIP思想）：度量、更新、坏消息传得慢（会解释）
  • 链路状态（OSPF思想）：泛洪、最短路、收敛快（会解释）
  • 路由表与转发：下一跳、接口、最长前缀匹配的转发表推导

第5章 运输层（简答+计算+综合：TCP 可靠传输/拥塞控制）

5.1 端到端与复用（名词解释高频）

  • 运输层提供的服务：进程到进程
  • 端口、套接字（socket）概念
  • 复用/分用：端口号如何定位应用

5.2 UDP（选择/简答）

  • UDP 特点：无连接、尽力而为、首部简单
  • 适用场景（实时/多播/DNS等）与优缺点

5.3 TCP 连接管理（综合题常考）

  • 三次握手/四次挥手：每一步目的、SYN/ACK/FIN、状态转换（必背）
  • 为什么握手是三次、挥手是四次（简答经典）
  • TIME_WAIT 为什么存在（简答高频）

5.4 TCP 可靠传输机制（计算/综合）

  • 序号、确认号、累计确认
  • 滑动窗口（发送窗口/接收窗口）、超时重传
  • RTT 估计与 RTO（知道思想即可）
  • 快重传、快恢复（常和拥塞控制一起考）

5.5 TCP 流量控制 vs 拥塞控制（多选/简答必考）

  • 流量控制：接收端通告窗口 rwnd
  • 拥塞控制：cwnd（拥塞窗口）
  • 四大算法：慢开始、拥塞避免、快重传、快恢复（会画/会描述窗口变化）
  • 可能的计算：给 MSS/RTT/阈值，问 cwnd 演进（考研难度很爱这样）

“按题型”最后再压一遍（你复习就按这个顺序）

单选（10题）

  • 分层/协议三要素/性能指标名词
  • 编码/复用/介质特性
  • 以太网帧、MAC/交换机/路由器区别
  • ARP/ICMP/TTL/分片字段
  • TCP/UDP特性、握手挥手要点

多选（5题）

  • 复用方式对比、CSMA系对比、GBN vs SR对比
  • 路由算法对比（RIP/OSPF思想）
  • TCP拥塞控制四算法特性与触发条件

简答（5题）

  • 冯诺依曼式：不需要；网络里常见的是：分层意义、可靠传输机制、CSMA/CD原理、ARP过程、三次握手/四次挥手/拥塞控制解释

计算（2题）

  • 香农/奈奎斯特（二选一几率大）
  • CRC 或 子网/CIDR 或 IP分片 或 TCP窗口/拥塞窗口演进（最常见）

综合应用（1题，15分）

  • 子网划分 + CIDR最长前缀匹配 + 路由表推导（最像考研综合）
  • 或 TCP建立/释放 + 可靠传输/拥塞控制综合叙述/判断抓包字段

附加题（30分）

  • 往往更偏“综合系统理解”：拥塞控制细节、链路层与网络层结合、抓包分析、traceroute原理、窗口演进大题等
