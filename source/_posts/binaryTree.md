# 二叉树
二叉树是一种树形数据结构

# 二叉树最小深度
最小深度是从根节点到最近叶子节点的最短路径上的节点数量。
要寻找整个二叉树的最小深度，可以转换成**寻找根节点左右节点**的最小深度，将问题逐渐化成子问题
所以返回是：
```java
min(l,r)+1;
```
递归的界限是节点为null，则返回0

## 注意事项
如果左右节点有一个节点是null的话，就可能导致该节点的值是0+1；
而最小深度要求的是叶子节点。
所以代码可以
```java
if(root == null) return 0;
if(root.left==null) return minDepth(root.right)=1;
if(root.right==null) return minDepth(root.left)=1;
return Math.min(minDepth(root.left),minDepth(root.right))+1;
```

# 哈夫曼树
哈夫曼树是一种用来解决二进制编码不出现歧义且编码长度最短的二叉树（也叫最优二叉树）其带权路径长度最短。
原本发送带权集合使用二进制编码然后压缩会出现歧义（某些数字的编码可能是另一个的编码的前缀，（10）b & （1）b ），使用哈夫曼编码可以同时解决这些问题。
e.g. 带权集合{15,4,4,3,2}
```plaintext
        28
       /  \
     13    15  （叶子节点：15）
    /  \
   5    8
  / \  / \
 2  3 4   4  （叶子节点：2、3、4、4）
```
**构建权值集合到哈夫曼树的过程**：
- 集合里面寻找最小的两个数作为左右节点；
- 想加得到父节点；
循环这两步直至集合内没有数字，此时就形成了哈夫曼树。
哈夫曼树中的左分支代表0，右分支代表1，从根节点到叶节点经过的0/1构成了哈夫曼编码（比如：3->001）;
